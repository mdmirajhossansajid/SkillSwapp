## 📖 About

**SkillSwap** is a front-end prototype for a skill-exchange platform — a place where people teach what they're good at in exchange for learning something new, instead of paying for it. No money changes hands; skills are the currency.

This repo contains a fully interactive, single-file HTML/CSS/JS prototype covering the core product experience: landing page, dashboard, user profiles, and a skill-matching flow.

## ✨ Features

- 🏠 **Landing page** — product pitch, feature highlights, and platform stats
- 📊 **Dashboard** — at-a-glance metrics, incoming skill requests (accept/decline), and upcoming sessions
- 👤 **Profile page** — bio, skills to teach vs. skills to learn, and peer ratings/reviews
- 🔍 **Matching** — searchable, filterable skill-matching grid with a compatibility score for each potential match
- 🎨 Clean, custom design system — soft teal/navy palette, DM Sans + DM Serif Display typography, no UI framework dependency

## 🚀 Getting Started

This is a static, dependency-free prototype — no build step required.

```bash
git clone https://github.com/mdmirajhossansajid/SkillSwapp.git
cd SkillSwapp
```

Then just open `index.html` in your browser, or serve it locally:

```bash
# using Python
python -m http.server 8000

# or using VS Code Live Server extension
```

## 📌 Project Status

This is a **UI/UX prototype** built to demonstrate the product concept and core user flows. It's not yet connected to a backend — matching, requests, and auth are illustrative rather than functional.

**Planned next steps:**
- [ ] Backend & database for real user accounts and skill listings
- [ ] Real matching algorithm (currently mocked scores)
- [ ] Authentication & session persistence
- [ ] Real-time messaging between matched users
